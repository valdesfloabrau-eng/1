# Onboarding a new domain project

1. Create a private repository named exactly as the domain.
2. Create a separate project root folder for that site.
3. Add project config with domain, locales, deploy targets, and branch strategy.
4. Register the project in the automation layer.
5. Attach deploy target adapter.
6. Define locale/subdomain mapping.
7. Start the first cycle:
   - create task spec
   - produce ask-first memo
   - choose option
   - open code PR
   - review
   - merge
   - deploy
