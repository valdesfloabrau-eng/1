# Task 002 — AkvaTonus desktop hero section

## What to build
Build and style one desktop hero section directly in Mottor for https://akvatonus.ru/.

This is not a full redesign pass. This is the first controlled desktop section only.

## Strategic direction
Transfer the strongest structural ideas from https://aquaslim.ru/ without cloning the visual shell.

What is worth transferring from the reference:
- one dominant offer in the first screen
- fast-scan value points near the top
- strong primary CTA for first visit
- clear trust layer
- clean left/right composition
- feeling of comfort + result + professionalism

What must NOT be copied literally:
- exact visual style
- exact wording
- aggressive medicalized promises that AkvaTonus does not currently support
- overloaded first screen

## Verified AkvaTonus facts that can be used
Use these as the factual base of the section:
- "до -6 кг и -5 см за курс без изнурительных диет"
- "видимый эффект после трех сеансов"
- "за 40 минут снимаем стресс мегаполиса"
- "убираем лимфатические отеки"
- current offer includes a first session discount of 20%
- the site already uses WhatsApp and Telegram as contact channels

## Section intent
The first screen should sell one thing clearly:
Hydromassage in AkvaTonus as a comfortable, effective, clean, expert-backed procedure.

Do not scatter attention across many massage types in this section.
Extra procedure categories belong lower on the page.

## Content direction
Recommended content skeleton:
- eyebrow with location/service context
- H1 focused on hydromassage in AkvaTonus
- compact supporting text about reducing volume, lowering puffiness, and bringing back lightness
- 4 fast value points based on verified facts
- primary CTA: "Записаться на сеанс"
- secondary lightweight contact option only if it helps composition
- one compact trust strip or trust badge layer

## Media rules
- do not insert real photos
- leave a visually correct image placeholder frame for later manual insertion
- if a video placeholder improves the section, add exactly one placeholder frame for the video
- the available video exists in both 9:16 and 16:9 but is the same content; do not duplicate it
- if needed, choose one neutral placeholder proportion that can later be cropped from the source, for example around 3:4 or 4:3

## Popup rule
The button "Записаться на сеанс" must open a popup in Mottor.
Follow the platform logic from the knowledge-base article:
- configure the action through the button click behavior
- prefer a block popup rather than a free popup unless you have a documented reason to do otherwise
- if you create the popup shell during this task, keep it simple and reviewable

## Mottor execution rules
- keep the layout realistic for Mottor
- avoid fragile decorative tricks that are likely to break in editor adaptation
- do not start mobile adaptation yet
- do not redesign the full page in one pass
- do not change unrelated sections in this task
